O incidente

Uma chave de API da Arcanjo SA vazou num commit público. A diretoria decretou: pipeline de segurança obrigatório em todos os repositórios. Este repositório é o pipeline de referência.

As três barreiras do pipeline

1. Gitleaks

Secret scanning. Varre o histórico do Git atrás de senhas, tokens e chaves de nuvem. Se achar, o pipeline falha.

2. Semgrep

SAST. Lê o código-fonte procurando padrões vulneráveis, como eval() com entrada do usuário.

3. Trivy

Scan de imagem. Builda a imagem Docker e bloqueia se ela tiver CVE CRITICAL com correção disponível.
